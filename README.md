# Interactive Portfolio Website

A modern, responsive, and interactive personal portfolio website built using HTML5, CSS3, and JavaScript. The website showcases personal information, technical skills, projects, achievements, and contact details through a visually appealing dark-themed interface.

# Features

- **Modern UI Design:** Clean dark theme with gradient accents and glowing effects.
- **Responsive Layout:** Optimized for desktop, tablet, and mobile devices.
- **Interactive Navigation:** Smooth scrolling between website sections.
- **Mobile Navigation Menu:** Hamburger menu for smaller screens.
- **Hero Section:** Introduction, call-to-action buttons, and developer code preview.
- **About Section:** Personal introduction and professional overview.
- **Skills Section:** Displays technical skills with visual progress indicators.
- **Projects Showcase:** Displays project cards with descriptions and technology tags.
- **Achievements Section:** Dedicated section for showcasing accomplishments.
- **Contact Form:** Interactive form with a submission confirmation message.
- **Scroll Reveal Animations:** Sections appear with animations as the user scrolls.
- **Cursor Glow Effect:** Dynamic glow follows the mouse pointer.
- **Hover Effects:** Interactive styling for buttons, skill cards, and project cards.
- **Accessible Navigation:** Semantic HTML and navigation accessibility attributes.

# Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Website structure and content |
| CSS3 | Styling, responsive layouts, gradients, and animations |
| JavaScript | Navigation, scroll animations, cursor effects, and form interactions |
| Google Fonts | Inter typography |

# Installation and Setup

Follow these steps to run the project on your local machine.

### Prerequisites

- A modern web browser, such as Google Chrome or Microsoft Edge.
- Visual Studio Code (recommended).
- Live Server extension for VS Code (optional).

### Step 1: Download the Project

Download and extract the project ZIP file.

Alternatively, clone the repository:

```bash
git clone <your-repository-url>
```

### Step 2: Open the Project

Open the extracted `Task-2 Interactive Portfolio` folder in Visual Studio Code.

### Step 3: Run the Website

**Option 1: Using a browser**

Open the `index.html` file directly in your browser.

**Option 2: Using Live Server**

- Integrate a dark/light theme switcher.
- Add live project previews and GitHub links.
- Improve SEO and accessibility testing.
- Add automated testing for interactive features.
