# Auspify — Interactive Portfolio Website

A modern, responsive portfolio website created from the provided Task 2 brief.

## Requirements implemented

- Multiple website sections
- Smooth anchor navigation
- CSS animations and hover effects
- Flexbox and CSS Grid layouts
- Responsive mobile navigation
- Portfolio/project showcase
- About section
- Skills and technology section
- Achievements timeline
- Interactive contact form
- Scroll reveal animations
- Desktop, tablet and mobile optimization

## Tech stack

- HTML5
- CSS3
- Vanilla JavaScript

## Run

Open `index.html` in a browser or use the Live Server extension in VS Code.

## Customize

Replace the placeholder name, email, links, project details and achievement text in `index.html`.
Colors, spacing and responsive breakpoints can be changed in `style.css`.
